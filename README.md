# Mirelle Lucien — Global Grant Funding Specialist

Premium, cinematic Slider Revolution-style Hero Section for **Mirelle Lucien** — Grant Writer, Grant Researcher, Proposal Writer, Grant Consultant, and Nonprofit Funding Specialist serving clients worldwide.

## ✨ Features
- **Cinematic Multi-Slide Presentation**: 4 thematic editorial slides (Intro/Brand, Grant Research, Proposal Writing, Consulting Strategy).
- **Slider Revolution Architecture**: Word-by-word / line-by-line masked reveals, ambient teal/cyan atmospheric lighting sweeps, architectural grids, and floating data matrices.
- **Tailored Executive Visual**: Professional corporate portrait of Mirelle Lucien wearing a black executive suit, seamlessly integrated with radial vignette feathering, rim-lighting, and ambient back-glow.
- **Parallax & Motion System**: Multi-layer mouse parallax depth calculation with spring lerp damping across foreground, portrait, and background layers.
- **Interactive HUD Controls**: Numeric slide indicator, synchronized duration progress line, slide tabs, WCAG-compliant play/pause toggle, prev/next arrows, and scroll-to-explore indicator.
- **Full Responsive Design**: Fluid typography with clamp(), stacked layout for tablet and mobile devices with touch swipe gestures.

## 🚀 Quick Start
Open `index.html` directly in any modern browser, or run a local server:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then visit `http://localhost:5510/`.
